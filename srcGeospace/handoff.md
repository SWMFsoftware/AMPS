## 7. Incidents and gotchas

### 7.1 Link-root race (fixed)
Private AMPS roots assembled from symbolic links (`$RUNS/work/core_cache/AMPS`,
`AMPS_repo`, `AMPS_oldcore`: links to the repository except `src` and the config files)
were used to build against modified/original cores.  `build_amps.sh` used `cp -a` for
`share/` and `input/`, which copies a link as a link, so those stages' `input/` pointed to
the repository `input/`: the deck `input/srcGeospace.input` was written into the
repository and shared by all such stages; parallel builds overwrote each other's
`ProjectSourceDirectory`.  Affected (compiled the wrong application, **invalid**):
`builds/geo_norm_oldengine`, `builds/geo_oldcore_oldrule`.  Valid: `merged_cpu_*`,
`srcgeospace_final`, `geo_oldcore_newrule`, `core_cache_cpu_double`,
`geo_norm_newengine` (verify with `grep -c 'bool dropped=false'
<stage>/build/main/gpu/EngineMesh.h`: 2 = new rule, 0 = old rule).
Fix: `build_amps.sh` copies directory contents (`cp -a "$REPO/share/." ...`) and refuses
a stage whose `share`/`input` is not a private directory.  The `input`/`share` links
inside existing stages were removed.

### 7.2 Others
* SA01-SA03 runners delete the repository `build/` and run `make -j` in the repository
  root **only with `--rebuild`**; the list entries do not pass it.  Never add it.
* MPI is initialized `MPI_THREAD_FUNNELED`: only the main thread may call MPI (fibers run
  on the main thread).
* Heavy tests (C19, C2 3d MESH; ~115-120 GB) must not overlap: two OOM kills earlier.
* The GPU build is correct but slower than the CPU for the test decks.
* GCC: `-std=c++17` does not disable FP contraction for C++; `-march=native` alone enables
  FMA and changes results.
