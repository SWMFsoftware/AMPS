# BG3D-4 projected-ambient consistency diagnosis

Date: 2026-11-10. Scope: the resumed G1/BG3D-4 convergence investigation.
These are diagnostic measurements and equation checks, not new qualification
receipts. No production ambient, piston, source, coefficient, fixture, or gate
was modified to obtain them.

## Observed difficulty

The unchanged full refinement executable exceeds its routine 180-second limit.
Progress instrumentation in a private copy finds a particularly stiff supported
ray, ID 106, with more than 900,000 accepted steps in its 3000--3600 s interval
at 40 initial cells. All four supported rays are still advanced. No smaller
ray set or larger CFL was used as an acceptance substitute.

A private algebraically stable shell-volume/centroid evaluation completes the
single 40-cell/3600-s diagnostic in 127.902 seconds. Its selected ray has **two
detected shock zones**. That is not a refinement PASS: the unchanged matrix
requires a single common branch, three mass levels, three time levels, and
the frozen numerical bounds. The complete unchanged-original coarse run takes 471.164 s and also detects
two zones, with the same printed shock diagnostics as the stable-shell run.
This isolates the algebraic speedup from the unresolved branch problem. A private exact degree-one PFSS
evaluation alone also exceeds the 180-second full-matrix limit; it has not
been imported into production.

Profiling finds both expensive ambient/PFSS evaluation and a large integration
step count. Improving field evaluation is insufficient evidence that the
production refinement is accurate or that its selected branch is consistent.

## A separate consistency issue requiring a physical decision

The selected Level-B closure evolves radial material velocity `u q_hat` on
fixed HCI rays, with immutable cell masses. It carries the maintained ambient
transverse velocity as an unevolved published component. Its mass equation
has no source or cross-ray exchange:

```text
partial_t rho + (1/r^2) partial_r(r^2 rho u) = 0.
```

Therefore a steady reference ambient on each such ray must satisfy

```text
partial_r(r^2 rho_a u_a,r) = 0.
```

This is an independent conservation requirement, not a reference value
generated by the production solver. Momentum-maintaining acceleration, thermal
heating, and magnetic source terms cannot repair a mass-balance mismatch.

The actual preserved `examples/bg3d4_piston/event.conf` supplies the three-
dimensional PFSS closed/open plus Parker ambient. Adjacent samples on every
currently supported ray cross from closed to open PFSS states. A closed state
has only corotation, so its radial mass flux is zero to roundoff. The open
state has substantial radial flux. The measured reference is not a steady
source-free one-dimensional mass solution on these fixed rays.

In three dimensions, transverse mass transport can balance a radial change.
The current Level-B equations explicitly omit that transport. The maintained
closure specification already identifies this omitted transport as a model
error; it must now be quantified rather than assumed small. The sampled
incompatibility is established. Its precise contribution to the extra shock
zones and timestep stiffness is a hypothesis until an unforced-reference and
causal-zone study isolates it.

## Choices that must not be made implicitly

The existing specification states that moving rays/cross-ray fluxes require an
expanded closure when validity diagnostics reject the radial approximation.
It also excludes inventing source terms, replacing missing states with ambient,
changing numerical tolerances, or discarding retained material. Accordingly:

1. **Retain the current three-dimensional ambient and expand conservative
   transport.** Define lateral mass, momentum, thermal/total-energy and signed
   magnetic transport consistently, plus contact/interface conditions. Recheck
   the prescribed regional-model scope; a global three-dimensional MHD solver
   is not implicitly authorized by a test repair. Qualification needs a steady
   unforced-reference test and independent transport/conservation/refinement
   tests before the actual driven production matrix can pass.
2. **Use a separately specified conservative radial ambient for the radial
   closure.** Such a reference must supply constant per-ray radial mass flux,
   compatible pressure/velocity/field and a documented relation to the shared
   three-dimensional background. This changes the physical experiment, so it
   cannot replace the frozen fixture silently. The original mixed-topology
   fixture must retain its own explicit validation result.
3. **Retain the radial closure and report its unsupported/invalid regime.**
   This is an honest limitation, not a fix for the required production gate.
   The current G1 and strict-coverage failures remain open.

Adding a fitted radial mass source merely to hold this reference steady would
violate the currently selected fixed-mass/no-source closure. Tuning source
strengths, removing ray 106, filtering out a detected zone, or weakening the
single-branch assertion is not an accepted repair.

The user explicitly selected option 1: **retain the 3-D ambient and develop
conservative cross-ray transport**. The implementation contract and staged
evidence are in [CONSERVATIVE_CROSS_RAY_TRANSPORT.md](CONSERVATIVE_CROSS_RAY_TRANSPORT.md).
The old per-ray fixture, its failures and all original gates remain retained;
this decision does not qualify a new regional provider or permit a silent
change of the legacy closure identity.
