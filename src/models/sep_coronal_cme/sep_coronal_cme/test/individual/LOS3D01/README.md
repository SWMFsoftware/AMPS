# LOS3D01

analytic transition masks recover the otherwise-source-eligible area, counterfactual number/energy-rate, and finite-footprint unsigned-flux numerators and denominators per registered stratum. Each cap is mutated past its threshold in turn and marks the manifest `not-event-grade`; a point observer is typed valid or rejected and never assigned a flux fraction.

Run from any directory with `python3 test.py`. The launcher delegates to the global registry, so individual and cumulative gates execute the identical implementation.
