# SCS3D09

analytic `G_ell` attenuation is reproduced for several shell thicknesses; an independent quadrature reproduces the gated absolute outer **zonal** non-monopole fraction and longitude-averaged latitude metrics under the HCS mask. An already-flat input passes at the same radius for which a structured input fails, and results converge with MPI partition, angular quadrature, and latitude bins.

Run from any directory with `python3 test.py`. The launcher delegates to the global registry, so individual and cumulative gates execute the identical implementation.
