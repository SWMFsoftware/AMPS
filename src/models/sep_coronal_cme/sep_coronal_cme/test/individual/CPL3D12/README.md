# CPL3D12

D9 crossing flux, null census, normal-trace jump, supported non-antipodality, sector mismatch, and immutable exclusion measures converge. A deliberately non-axisymmetric inherited sheet cannot use a future common-flux-surface policy unless both one-sided tangency and unique-partition gates pass.

Run from any directory with `python3 test.py`. The launcher delegates to the global registry, so individual and cumulative gates execute the identical implementation.
