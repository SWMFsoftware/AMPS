# I11 — AMR spatial-resolution convergence

The [event-budget contract](BUDGET_CONTRACT.md) adds an automatically executed
production ledger/chemistry prerequisite after the sampling-window check.
`run_all_test.py` reaches both through the existing I11 registration. Five
additional `test_diagnostics.py` analytical/parser checks run automatically
with the ten infrastructure tests. No permanent test ID is added.

The November 12 audit found the generic Exosphere chemistry processor never
removed Na: its private lifetime table excludes that species. The canonical
input now dispatches `Moon::Chemistry::ProcessParticle`, retaining the existing
Moon lifetime and shadow law. Linked sunlit/shadow survival checks expose the
former bypass and protect actual dispatch; prior duration studies cannot
qualify the corrected physics. Nightly reference changes require review.

`particle_budget.csv` has one row per checkpoint, with explicit completed
particle-step and elapsed-time columns. `particle_sources.csv` writes the
complete registered source-ID table once per checkpoint in the same order.
Its repeated `sample` label is not a unique join key: pair complete source-ID
groups with budget rows by ordinal position and verify the labels and IDs.
Source IDs are generated by the configured build; use the written symbols,
not a presumed fixed numbering. Reservoir-supply counts mean nonzero facet
prescription operations, while reservoir weights are signed atoms; neither
is a gas-emission event.

The budget figure converts each ledger interval's actual weighted events to
atoms/s using its elapsed particle time, including a short final closing
interval. This prevents the cooperative stop from creating an artificial rate
drop. Raw atom totals remain in the ledger; no interval is discarded or
smoothed. Reprocessing must use a new diagnostics directory so earlier
scientifically meaningful figures and their processor hashes are preserved.

The existing I11 wrapper automatically runs `test_infrastructure.py` before
MPI launch. Ten isolated tests cover both approved sequences, fixed
far-field/physical controls, exact finest-input reproduction for I13, and
rejection of unapproved custom settings. They also freeze the 500-step sample,
5000-step per-resolution cap, disabled particle-restart build setting, and the
separation between formal I11 and the non-qualifying duration pilot.
Three scheduler tests verify exit-code preservation, process cleanup at the
runtime budget, and the aggregate-memory guard. A species-builder preflight
test verifies that a refused filename collision preserves the existing input.
These tests generate only temporary
input files, not observations or science baselines. Infrastructure success
does not contribute a numerical-convergence PASS.

I11 uses the normal SPICE-enabled Moon executable and the reviewed spherical
M1 receipt. The approved 2026-10-14 memory campaign uses
`m1_memory200.in` and immutable 480, 240, 120, and 60 km child receipts.
The legacy FULL template retains its 40/20/10/5 km sequence when explicitly
selected. Other CUSTOM and QUICK meshes are rejected. The runner is
changing only spatial-resolution targets. Each linked run proves that
`simulation_environment_mode=frozen` holds ephemeris time, Sun/Earth states,
and rotating-frame angular velocity fixed across normal production particle
steps. Particle transport remains enabled with its positive production time
step; this is not a no-force test mode.

The vector includes all configured density profiles, six predeclared
30-degree solar-zenith-angle surface-return-flux bands and their global
integral, both Earth-view limb branches for
Na column density and both D-line brightnesses, and global inventory. Base
blocks use the production sampling interval. Batch duration doubles until
lag-one correlation is statistically insignificant; four independent means
establish three consecutive <=2% equilibrium changes, and the following five
means are scored with Student-t 95% intervals. CI half-widths must be <=1.67%
for integrated quantities and <=3.33% for pointwise bins. Successive grids
must change integrated observables by <5% and pointwise bins by <10%.

The user-approved bounded campaign uses **500 particle iterations per completed
sample** and stops each resolution after at most **5000 particle iterations**.
This produces at most ten base samples, enough to evaluate the unchanged
nine-batch statistical minimum once if the raw blocks are already independent.
It does not guarantee qualification: correlation-driven batch aggregation,
equilibration, or confidence-width failure at the cap remains `FAIL`, never
`PASS` or `SKIPPED`. The runner still executes all four resolutions and retains
their raw block/resource artifacts. This bound is an execution policy, not a
relaxation of a failed criterion.

Immediately after every completed resolution, including a capped `FAIL`, the
runner writes `stage_diagnostic.csv`, `.png`, `.eps`, and `.json` in that
resolution directory. The first-stage figure compares its raw samples with
their raw stage means. Later figures add cumulative raw-mean comparisons with
completed coarser stages. Every artifact is marked `DIAGNOSTIC ONLY - NOT
OBSERVATIONAL VALIDATION`; it is never read by formal scoring and never
substitutes for accepted `qualified_metrics.csv` or `convergence_metrics.csv`.

Concurrent scheduling also writes an early `stage_diagnostic_pending.*` set
as soon as a mesh finishes, using the completion order available then.
`PENDING` means formal scoring has not happened; it is never counted as a
PASS/FAIL/SKIPPED/ERROR result. Final scoring writes the ordinary
`stage_diagnostic.*` files in coarse-to-fine order and preserves the preview.

The four child inputs scale the surface, near-surface, angular, and polar
targets to the selected sequence (default: 480, 240, 120, and 60 km).  The far-field and outer-domain targets and
all physical extents remain fixed, because refining a remote tail region does
not estimate near-Moon discretization error and previously caused an
uncontrolled block-count increase.  All point samples, shell integrals,
surface bands, and inventories are reduced across their actual MPI owners;
only rank zero writes the common artifacts.

For the memory campaign the fixed far-field target is 480 km (not the initial
240 km allocation-only candidate): the production parser requires far >= near,
including the 480 km coarse member. Derivation checks this invariant before
MPI launch and never silently clamps an individual member. This change is
numerical, not a physical-domain or source change. Far-field discretization
error remains outside the near-surface convergence claim.

The default serial path has no wall-time or memory guard beyond the explicit
5000-iteration bound; the optional parallel path applies the aggregate guards
documented below.
`process_resource_metrics.csv` covers
initialization and the mpiexec process tree, while `resource_metrics.csv`
records completed production blocks. Actual allocator exhaustion uses the
AMPS fatal exit with reduction guidance and yields `ERROR`.

I11 suppresses completed-sample visualization writers while retaining normal
production sampling, buffer exchange, and the I11 scoring callback. The
2026-10-31 run showed that repeated volumetric and velocity-distribution text
files accounted for nearly all of the 20--71 GB retained per level, but they
are not scoring inputs. Required evidence remains in `block_metrics.csv`,
`analysis_diagnostics.csv`, `resource_metrics.csv`, the receipt, logs, input,
manifest, and diagnostic figures. `analysis_diagnostics.csv` records, for each
admissible batch size, counts failing independence, equilibrium, and CI; these
diagnostics do not change thresholds or batch selection.

Particle restart output is compiled off in `input/moon.input`. Particle-only
restart files cannot recover the in-memory I11 sampling/batch state and were
the main source of misleading disk consumption. No valid restart/resume claim
is made; a rerun begins in a new output directory from iteration zero.

`srcMoon/examples/m1_regression.in` is the bounded default linked wiring
receipt and `m1_quick.in` is the intermediate production-wiring profile.
Neither can be supplied to I11 as convergence evidence.

Run from the repository root with a clean SPICE Moon executable:

```sh
python3 srcMoon/test/integration-tests/I11/test.py \
  --amps ./amps \
  --input srcMoon/examples/m1_memory200.in \
  --output-dir test_output/srcMoon/I11
```

The output contains a directory per resolution with logs, receipt, result,
manifest, immutable input, raw block metrics, resource histories, and runtime
products. `qualified_metrics.csv` and accepted `convergence_metrics.csv` exist
only if the unchanged gates actually pass before the cap. The parent always
contains the campaign manifest and aggregate `result.json`.

## Coarsest-grid physical-duration pilot

137 (MPI rank 2 received SIGKILL). Its sampled density/inventory is affected by
the cell-buffer reset defect documented in [SAMPLING_CONTRACT.md](SAMPLING_CONTRACT.md).
It cannot determine an equilibrium duration. The defect is repaired in the
common PIC sampler: output flags no longer control buffer resets.

Every qualification invocation now first runs the deterministic linked
sampling check, preserving `I11/sampling_check/` and `sampling_check.log`.
To run the check separately with a clean Moon/SPICE executable:


is a ghost slot and is not a valid oracle for the owned-cell reset. To check a
real two-species layout, build the explicitly scoped Na+Ar storage fixture:

For an approximately one-hour test window, run all four isolated meshes with
eight MPI ranks each (32 hardware threads total). This machine has 18 physical

```sh
python3 -B srcMoon/test/run_all_test.py --skip-build \
  --amps ./amps --campaign-mode qualification \
  --m1-input srcMoon/examples/m1_memory200.in \
  --only I11 --only I12 --only I13 --mpi-ranks 8 \
```

Each launch has its own runtime/cache directory. `I11/campaign_resources.csv`
records aggregate RSS, available host memory, disk and elapsed time. The
parallel scheduler enforces 200 GiB aggregate RSS, 8 GiB available host RAM,
100 GiB disk free and the explicit launch-time budget. Incomplete children
are ERROR; completed children keep their evaluated results. Preliminary
per-stage plots are marked SKIPPED until the ordinary scorer processes them.
The formal 500/5000-step policy and all scientific thresholds are unchanged.
Serial I11 remains the default and retains its existing execution policy.

`particle_diagnostics.csv` records instantaneous Na model-particle count and
physical weighted inventory from the real particle lists, independently of
the completed density-window integral. These are diagnostic quantities with
different time meanings; they are not an I19 closed event budget. The sampling
fixture checks dimensionless storage markers and supplies no observations.

I11 also emits `I12_initialization_receipt.txt` and
`I13_initialization_receipt.txt` from the same allocated production mesh.
The corresponding independent scorers reuse the finest receipts only after
matching the input, executable and MPI identities. I12 retains its own result.
I13 still requires same-campaign I11 PASS and explicit review/freeze of its
candidate; candidate generation cannot approve a reference. Once frozen, a
subsequent independent passing campaign supplies reproduction evidence.

The retained 2026-10-31 campaign used unequal physical durations because the
production timestep halves at every refined mesh. Before changing the formal
four-grid contract, run the distinct 480 km pilot:

```sh
python3 srcMoon/test/integration-tests/I11/run_duration_pilot.py \
  --amps ./amps \
  --input srcMoon/examples/m1_memory200.in \
  --mpi-ranks 8 \
  --memory-limit-gib 200 \
  --minimum-host-available-gib 8 \
  --minimum-free-disk-gib 100 \
  --output-dir test_output/srcMoon/I11-duration-pilot-YYYYMMDD
```

The pilot uses the same production physics, seed, frozen epoch, 500-step raw
samples, scoring vector, and unchanged independence/equilibrium/CI gates. It
has no scientific iteration ceiling. Its default 3600 s wall budget requests
a cooperative stop between complete production steps, with a 30 s grace
period. Use `--wall-seconds` and `--stop-grace-seconds` to set these operational
limits explicitly. It can also stop when the gates pass, a resource guard
fires, the program errors, or the operator interrupts it. The 200 GiB
process-tree RSS guard honors the approved host
budget; host-memory and filesystem floors prevent avoidable system or disk
exhaustion. A guard terminates the complete MPI process group and writes
`resource_guard_termination.json` with the reason and remediation.

A successful run writes `pilot_result.json` with `pilot_status=COMPLETE` and
`formal_i11_status=NOT EVALUATED`. It reports exact candidate total, batch,
equilibrium-window, and science-window durations. Those values require review
and explicit freezing before conversion into grid-specific step counts. Pilot
completion is not I11 PASS, creates no cross-grid metrics, and cannot open I13
or M2.

A normal wall-budget stop writes `pilot_status=PARTIAL`, a final receipt and
closing event snapshot, with no candidate duration. Its zero launcher exit
means the bounded diagnostic completed normally, never formal I11 PASS.
Resource/runtime failures are ERROR; an evaluated event-ledger violation is
FAIL. Both storage and chemistry/ledger prerequisites execute first with the
same executable/input/rank identities and retain their separate results.
The launcher prints live RSS/time progress every minute.

New per-stage files are `particle_budget.csv` (instantaneous inventory and
interval events), `particle_sources.csv` (cumulative accepted emissions by
registered source ID), and `diagnostics/metric_statistics.csv` plus PNG/EPS
statistics/budget figures and `diagnostics.json`. Raw sampling occurs before
that step's injection/chemistry/motion; completed-step labels preserve this
timing and the final post-step row accounts for the remainder. Reservoir
replenishment is a signed external surface supply, not a gas birth. Model-count
closure must be exact; weighted closure uses the documented roundoff bound.
Known numerical removals are reported separately and prevent qualification.

The processor retains every metric, reconstructs the declared gate algorithm,
and checks the first reached gates against production diagnostics. It does
not choose a new startup cutoff, alter scores, or create accepted convergence
means. Zero empirical support is flagged for the existing statistical-support
audit proposal rather than silently promoted to physical certainty.
