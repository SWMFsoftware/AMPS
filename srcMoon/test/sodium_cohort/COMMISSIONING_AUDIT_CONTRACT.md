# Single-level source-bound sodium commissioning audit

Contract recorded before implementation, 2026-11-19. No new U/I ID is assigned.

Purpose: audit an actual completed conditional native sodium run without
claiming the multi-level numerical or statistical gates of I21. Production
entry points are the existing normal-startup physical owner, controller,
transaction, mover and semantic stream; this audit only reads their artifacts.
The input is the existing `srcMoon-M3-P02-owner-binding-v1` binding with pinned
profile, explicit approved-budget file and completed owner manifest/result
descriptors plus actual 1/8 MPI layout. No producer/permission/readiness flag
is manufactured. The P02 cap auditor remains a separate owner.

Procedure: authenticate each original completed owner with
`audit.authenticate_launch`, authenticate its original root input and complete
application include graph, compare profile/state conventions, read the complete
original-parent range, and require exact equality with the per-rank first-event
set. Reuse `verify_ledger.verify/write_artifacts` for independent exact-rational
committed-child/bath/nuclei/charge/momentum/energy checks; reuse the maintained
source parser, native time links and fixed I21 inverse-square checks. Independently
reconstruct each source uniform with the maintained Python HMAC oracle and use
the closed-form first-event time `-ln(U)/lambda` at Decimal precision80.

Units/frame/time: native SI, LSO geometry, explicit frozen furnished-SPICE ET,
and advancing physical relative seconds from the actual transport origin.
The source reference distance and visibility come from the authenticated
receipt. Original D04 data/QA/provenance and profile/source hashes are checked;
no observation is synthesized or modified. No constant-rate score is permitted
for a trajectory-dependent case.

Metrics/criteria: complete source/input/artifact and parent/event identity;
per-parent removal membership; normalized first-event-time error divided by the
actual physical horizon at the existing approved I21 **0.002** allocation;
the unchanged independent inverse-square **0.001** criterion; exact ledger
criteria with the original explicit native bounds. Single-level timing PASS
means only this supporting error check passed. It is never refinement PASS.
Survival counts and independent expected survival are diagnostic only: no
lifetime/branch confidence or ensemble acceptance is scored.

Artifacts in a new output directory: result/manifest/log, comparison CSV/PNG/EPS,
per-owner time-link/inverse-square/ledger outputs, and survival diagnostics.
Existing output directories are preserved. PASS/FAIL apply only to evaluated
supporting criteria. Missing prerequisites are SKIPPED; contradictory/corrupt
bindings, parser or infrastructure failures are ERROR. Formal M3 remains
SKIPPED / NOT QUALIFIED, and refinement/statistical qualification remain
NOT_EVALUATED regardless of supporting results.

Software controls must not fabricate a successful native owner. Negative tests
use missing/corrupt administrative bindings. Analytical helper fixtures test
the independent exponential identity and endpoint semantics only, never physical
source readiness or an observed result. Actual native auditing is separate.
