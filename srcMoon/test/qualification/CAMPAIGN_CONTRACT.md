Before the first launch, freeze the complete ordered set of case slots and
their exact input SHA-256s in a JSON plan. Each I21 slot uses an existing
predeclared native cohort plan with its 1/8-rank matrix, keyed original-parent
stream, epoch and source-state profile. I24 slots use the pinned r14 lock,
NIST state inventory and, for particle execution, a source-matched SPICE
producer. The independent scorers use LSO Cartesian SI quantities and elapsed
physical seconds at the frozen UTC geometry or the case's declared
target-rest frame. Keep the source references and approved numerical,
statistical and signed-ledger criteria of each test. I21 per-parent timing
differences between ranks are reported as diagnostics, while the existing
independent first-hit refinement still scores timing. The bounded I21
development cohort does not score its underpowered ensemble as formal lifetime
evidence. Do not pool matched MPI layouts or different cases as extra
independent trials.

One outer monotonic budget covers every child, aggregate RSS and total output
size. Test runs are serial with one OpenMP thread per process. Each child uses
the original production runner and verifier, retaining its own limits and
scientific artifacts. Beyond available resources defer to the cluster tier.
The family audit retains exact commands, plan, inputs, tool/source revision,
per-case logs and manifests, observations of resource use, machine-readable
results and a case/check CSV. Child CSV/PNG/EPS and native diagnostics remain
at their original locations under the family directory. No observations are
an input to this campaign.

PASS requires every selected supporting case to complete and pass its own
independent tests. Missing required evidence yields SKIPPED for that case.
Changed or malformed pins, contradictory child exits/results, unbound native
artifacts and resource termination yield ERROR. A measured criterion that
misses its bound is FAIL. Each outcome retains the original evidence and
independent later cases can run within the remaining budget. In a mixed
family precedence is ERROR, FAIL, SKIPPED, PASS. The formal I21–I24 owners
keep their independent results and same-campaign I13–I20 and applicable
U predecessors. This runner does not award formal PASS from a development
family. Model completeness remains a prerequisite.
