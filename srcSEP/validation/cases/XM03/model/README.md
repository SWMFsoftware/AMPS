# Retired external-result directory

XM03 no longer reads `model/srcsep_output.csv`. The selected linked
`srcSEP/AMPS` executable produces `XM03_model.csv` in the run's `native/`
evidence directory. This placeholder is retained only so old worktrees do not
mistake the disappearance of the directory for a packaging error.

Run the case with:

```sh
python3 test/run_tests.py --amps ../amps --validation-case XM03 \
  --output-dir test_output/XM03
```

Do not place a manually reconstructed, digitized, or SOFIE-derived curve here:
the Figure 12(a–c) Earth observations are the immutable reference, and every
model row must be generated by the linked executable during the current run.
